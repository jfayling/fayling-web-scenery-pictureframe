# Changelog

## 1.0.0 (unreleased)

First public release. See [release notes](docs/releases/v1.0.0.md).

- Nine procedural Earth regions and five measured lunar regions with autonomous flight
- GitHub Pages live demo, deployed by GitHub Actions from the minified bundle
- CI: build, bundle freshness check, unit tests, and Pages site check
- Open Graph and Twitter card metadata, canonical URL, and social preview image
- Friendlier error page when WebGPU is unavailable, linking to browser support
- `step=` screenshot parameter and `tools/make-media.mjs` for regenerating README media
- Documentation: browser support, troubleshooting, contributing, attribution, issue and PR templates
